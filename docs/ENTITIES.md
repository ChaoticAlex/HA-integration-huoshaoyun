# 实体与数值含义

每个地点 **6 个实体**。以下说明每个数值的**量纲、范围与读法**——它们都是原始数值，
本集成不做任何评级或推荐，"多少分算值得出门"由你自己的自动化决定。

## 1. `今日朝霞` `今日晚霞` `明日朝霞` `明日晚霞`

| 项 | 说明 |
|---|---|
| 数值 | **鲜艳度指数，0 ~ 2.5，无量纲** |
| 0 的含义 | 没有"既被低角度阳光照亮、又在你视野内"的云（晴空、或云全在阴影里、或被低云挡住） |
| 越大越好 | 是。约 2.5 是理论上限，实际极难达到 |
| **不是**概率 | 不能读作百分比，也不能与其他产品的分数直接比较 |
| 可比性 | 同一天 4 个事件之间、或自己历史纵向比较有意义 |
| 事件 | `今日/明日` 指事件发生在今天/明天，`朝霞`=日出、`晚霞`=日落 |
| 已过的事件 | 保留数值，便于复盘预报准不准 |

属性（键名与顺序稳定，缺失一律 `null`，不造假值）：

| 属性 | 类型 | 含义 |
|---|---|---|
| `事件时间` | `YYYY-MM-DD HH:MM` | 该事件（日出/日落）的本地时刻 |
| `距今小时` | 数值 | 距该事件还有几小时，**负值 = 已过**。适合写成自动化条件 |
| `已过` | 布尔 | 事件是否已经发生 |
| `太阳方位角` | 度 | 朝霞/晚霞该往哪个方向看，0=北 90=东 180=南 270=西 |
| `峰值` | 0~2.5 | 亮面分数的时间序列最高值（未乘持续时间因子） |
| `峰值时刻` | `HH:MM` | 峰值出现的时间，通常就是日落/日出那一刻 |
| `有效时段` | `HH:MM-HH:MM` | 分数高于阈值的时段，即"实际能看的窗口" |
| `持续分钟` | 分钟 | 有效时段长度。火烧云短促，10 分钟很正常 |
| `气溶胶光学厚度` | 0~3 | 该事件光路上的 CAMS AOD，见下文；缺失为 `null` |
| `云层` | 文本 | 观察者上空的云层人读描述，如 `中云 5.9-6.7km RH87% T-9℃` |
| `云量来源` | 文本 | `均值`(默认) / `诊断云量` / `廓线反演` |
| `各模式数值` | 字典 | 每个模式的分数，以及该模式的诊断云量/廓线反演两个口径的分数 |
| `时间序列` | 文本 | `18:06:1.02, 18:11:0.88, 18:16:0.09`，便于看过程 |
| `数据指纹` | 文本 | 模型输出哈希。**变了才代表换了起报**——分数没动通常是数据没动 |
| `数据变更` | 布尔 | 本次刷新是否拿到了新起报 |
| `数据完整` | 布尔 | `false` = 有模型层或 AOD 没取到，数值置信度较低 |
| `缺失数据` | 列表或 `null` | 例如 `["650-400hPa", "CAMS AOD"]` |
| `口径` | 文本 | 该数值怎么算出来的（自述，避免误读） |

## 2. `气溶胶光学厚度`

| 项 | 说明 |
|---|---|
| 数值 | **CAMS 气溶胶光学厚度 AOD，0 ~ 3，无量纲**（垂直气柱的消光总量） |
| 0.1 以下 | 空气很通透，霞的饱和度与亮度都好 |
| ~0.3 | 中等浑浊，颜色会明显发闷（很常见的城市背景值） |
| > 0.5 | 浑浊，基本告别鲜艳的霞 |
| 参照对象 | **"下一次霞光"**（哪一次见 `对应事件` 属性） |
| 取数方式 | 沿日落/日出方位 9 点采样，按 `exp(−x/250km)` 距离加权 |
| 缺失 | 为 `null`，且此时评分按中性 0.2 参与计算（**不造假值**，但分数会偏高约 15%） |

另含属性 `各事件AOD`，一次列出 4 个事件各自的值。

## 3. `云况诊断`

state **不是数值**，是云层类别标记：

```
none            没有任何一层云量达到 0.10
low / mid / high          只有该层有云
low+mid 等      组合，按 low、mid、high 顺序连接
```

各类别的明细在属性里（**schema 稳定**：键总是存在，无湿层则为 `null`）：

| 属性 | 类型 | 含义 |
|---|---|---|
| `主导云层` | `low`/`mid`/`high` | 云量最大的那一类 |
| `主导云底_m` | 米或 `null` | 主导云层（**湿层**）的云底高度 |
| `低云_云量` `中云_云量` `高云_云量` | **0~1** | 云量分数（与评分同口径，多模式取均值） |
| `低云_云底_m` `中云_云底_m` `高云_云底_m` | 米或 `null` | 该层 RH≥78% 湿层的底；`null` = 该层无湿层 |
| `低云_云顶_m` `中云_云顶_m` `高云_云顶_m` | 米或 `null` | 同上，湿层顶。顶端=底端表示该层只有一层达标 |
| `低云_温度_C` `中云_温度_C` `高云_温度_C` | ℃ 或 `null` | 湿层内温度 |
| `低云_相态` `中云_相态` `高云_相态` | `ice`/`water`/`null` | 按 0℃ 线；冰/混合相态更艳 |
| `各事件标记` | 字典 | 4 个事件各自的类别标记 |
| `文字描述` | 文本 | 人读版，含**每个模式**的原始层信息 |
| `标记口径` `云量口径` | 文本 | 口径自述，避免误读 |

> 分类按**云底高度**：`<2.5 km` 低 / `2.5~6 km` 中 / `≥6 km` 高。
> 云量取 `均值` 口径时是"模式诊断"与"湿度廓线反演"的平均值。

## 4. 写自动化时的几个要点

- **别用 `state` 直接比大小判断云况**——`云况诊断` 是类别标记，判断请用属性里的 `*_云量`
- **判断"值不值得拍"用 4 个事件实体的数值**，条件建议叠上通透度：
  ```jinja
  {{ states('sensor.<地点>_jin_ri_wan_xia')|float(0) >= 0.4
     and state_attr('sensor.<地点>_jin_ri_wan_xia','气溶胶光学厚度')|float(9) < 0.25 }}
  ```
- **避免对已过事件触发**：加上 `state_attr(...,'距今小时')|float(0) > 0`
- **补数据完整性检查**：`state_attr(...,'数据完整')` 为 `false` 时分数置信度低，
  可考虑降低提醒级别或直接跳过
- 实体 ID 以 开发者工具 → 状态 里看到的为准（中文名称可能生成含中文的 ID）
