# 算法说明

## 0. 它到底算什么

**鲜艳度 = 被低角度阳光照亮的云，占据你天空的"有效亮面"有多大 × 云的相态好坏 × 空气通透度 × 持续多久。**

不是概率、不是百分比，是一个 0~2.5 的**无量纲指数**：0 = 没有可见的亮面云；越大越鲜艳、越值得看。
它不是官方数值，与其他产品的分数**不可直接比较**，但同一天内 4 个事件之间、以及自己历史纵向比较是有效的。

## 1. 几何：火烧云三角

日落后（或日出前）太阳在地平线下 `s` 弧度，则**晨昏线**（地球阴影边界）距你 `d = R·s`：

```
太阳下沉 1° → d ≈ 111 km；在观察者上方，地球阴影高度 ≈ 0.97 km（故有"下沉1°≈阴影1km"的经验值）
```

高度 `z` 的云层：

| 条件 | 公式 |
|---|---|
| **被直射光**照亮 | `z > (x − d)² / (2R)` |
| **被你看见**（高于地平切线） | `z > x² / (2R)` |

`x` = 沿日落（日出）方位到云的水平距离。两式联立 ⇒ **亮带**：

```
x ∈ ( d − √(2Rz),  d + √(2Rz) )   ∩   ( 0, √(2Rz) )
```

`√(2Rz)` 就是"霞光深入距离"：云底 2 km → 159.6 km（亮带总宽 319.2 km，与原作者公开教程的表一致，可作公式校验）。

**由此得到的实用推论**：

| 云底高度 | 能持续到太阳高度 | 说明 |
|---|---|---|
| 1.5 km 低云 | ≈ −1.2° | 只烧几分钟，之后变剪影 |
| 5.5 km 中云 | ≈ −2.4° | 典型晚霞主力 |
| 9 km 高云 | ≈ −3.0° | 烧得最久，日落后十几分钟仍在亮 |

朝霞与晚霞**几何完全对称**：只需换成日出方位、把窗口取在日出前。

## 2. 评分公式

```
S(t) = [1 − exp(−Σ_c P_c·pw_c)]      # 亮面云量(立体角加权)，软上限 1
       × (1 − 0.85·D)                # 处于阴影中的可见云 → 剪影挡光
       × exp(−0.9·AOD)               # 大气浑浊度衰减
       × exp(−0.15·|太阳高度角|)      # 太阳越深，照明越弱
       × 1.45                        # 标定：使"理想大烧"≈1.0

鲜艳度 = S_peak × ( 0.4 + 0.6·min(1, 有效分钟 / 25) )
```

**各项是怎么来的**

- **`P_c`（亮面云量）**：沿日落/日出方位取 9 个断面点（0/30/60/100/150/210/270/330/400 km），
  对第 `i` 个环带取 `环带立体角份额 w_i × 云量 c_i`，只累加**既被照亮又被看见**的环带。
  立体角份额按云盘真实视面积算：`S(X) = 1 − z/√(X²+z²)`，于是 0–30 km 环带权重高达 ~0.8，
  **头顶的云远比地平线上的云重要**（符合"火烧云主要烧在头顶"的观感）。
- **`pw_c`（相态/云型权重）**：冰或混合相态中高云 `1.00`（最鲜艳）；液态水云 `0.80`；
  高空薄卷云(T<−35℃) `0.55`（亮但淡）；深厚对流云(厚>4 km) `0.35`（自遮挡）；该层无湿层时按 `0.75` 占位。
- **`1 − exp(−Σ)`**：亮面云再多也不能超过整个天空，软上限而不是硬截断。
- **`D`（遮挡）**：可见但落在阴影里的低云按 1.0、中云按 0.5 计入（它们挡在你和亮区之间）。
- **AOD**：沿光路上游按 `exp(−x/250km)` 距离加权取 CAMS 气溶胶，再乘 `exp(−0.9·AOD)`。
- **持续时间**：`S > max(0.05, 15%·峰值)` 的分钟数；25 分钟算满分，更短按比例扣。

## 3. 云量与云高的口径

- **云量两种口径**，都算出来、都放在实体属性里：
  - **诊断云量**：模式自己输出的分层云量
  - **廓线反演**：气温/湿度廓线里 `RH ≥ 78%` 的联通湿层，云量取 `(RH_max − 78) / 22`（与阈值连续）
  - 默认取**两者均值**；两者常分歧明显（实测遇到过"模式诊断 0% 而同层 RH 88%"），
    换口径会让单口径结果整体移动约 ±30%、均值移动约 ±15%
- **分层按云底高度**：`<2.5 km` 低云 / `2.5~6 km` 中云 / `≥6 km` 高云
  （决定"能不能被照亮"的是云底，故按云底归类；同一层饱和气团不会被同时算作两类）。

## 4. 判断实例

> 以下输入为便于复算的**构造示例**，与任何具体地点无关。云量按各断面点均一处理。

### 例 A：中云晚霞 → 0.29「小烧~中等烧」

输入：日落 18:06；中云底 5.9 km / 顶 6.7 km（RH 88%、T −9℃ → 冰相态 `pw=1.0`）；
各点云量 0.6；AOD 0.37；`z=6.3 km` 时可见范围 `√(2Rz)=283 km`。

| 时刻 | 太阳高度 | 阴影线 d | 亮带 ∩ 可见 | `P` | `C_eff` | 遮挡 | 照明 | `S` |
|---|---|---|---|---|---|---|---|---|
| 18:06 | 0° | 0 km | 0–283 km 全亮 | 0.59 | 0.44 | 0 | 1.00 | **0.46** |
| 18:11 | −1.0° | 111 km | 仍全覆盖 | 0.59 | 0.44 | 0 | 0.86 | 0.40 |
| 18:16 | −2.9° | 322 km | 仅 45–283 km | 0.11 | 0.11 | 0 | 0.65 | 0.07 |
| 18:21 | −4.0° | 450 km | 仅 167–283 km | 0.01 | 0.01 | 0 | 0.55 | 0.00 |

峰值 `0.46 @18:06`，有效 10 分钟（阈值 0.069）→ 持续因子 `0.4+0.6×10/25 = 0.64`
→ **鲜艳度 = 0.46 × 0.64 = 0.29**。

**实际场景**：日落时西侧天空有一片中层云被点亮，颜色由橙转红，约 10 分钟内从最内侧开始
变暗熄灭，之后只剩云的黑色剪影。属于"值得抬头看一眼，但不值得专程出门"。

### 例 B：高云大烧 → 0.83「大烧」

输入：中高云底 6.3 km、冰/混合相态（`pw=1.0`）、**云量 1.0（铺满）**、AOD **0.10**、
有效持续 **25 分钟**。

`P = 0.98 → C_eff = 0.62`；`AOD 因子 = 0.91`；峰值 `S = 0.62×0.91×1×1.45 = 0.82`
→ 持续满分 → **鲜艳度 0.82**。

**对照**：同一片云若只有 **8 成**且持续 **10 分钟** → `0.72 × 0.64 = 0.46`；
若云量满分但 **AOD 0.37**（中等浑浊）→ `0.62×0.72×1.45 = 0.65`。

> 结论：**大烧需要"近乎满天的亮面云 + 很干净的通透度 + 足够长的持续时间"三者同时具备**，
> 缺一项就掉一档。这也是把它做成 0~2.5 而不是 0~1 的原因。

### 例 C：低云封天 → 约 0.3，且只有几分钟

输入：低云底 1.5 km、云量 0.9（液态水云 `pw=0.80`）、AOD 0.40。
日落那一刻确实有 `S≈0.53`（云底被从下方打亮），但：
`z=1.5 km` 可见范围仅 `√(2Rz)=138 km`，太阳一沉到 −1.5° 以下，阴影线就把整片低云盖住
→ `D` 迅速占满、`P` 归零。持续通常 5 分钟，**总分 ~0.3**。

**实际场景**：整片低云在日落瞬间泛一阵暗橘色，随即全黑，观感通常很差（浑浊时更差）。

### 例 D：有云但没光 → 0

太阳已沉到 −5°，阴影线推到 556 km 外，而 5~6 km 中云的可见范围只有 ~280 km
→ 可见的云**全部**落在阴影里 → `P=0`。这就是为什么"日落 20 分钟后突然想起来看天"通常已经晚了。

### 例 E：晴空无云 → 0

`P=0` 无论 AOD 多好都是 0。**通透度只在"有云可烧"的前提下才有意义**。

## 5. 各档分数的含义（含出门建议）

| 分数 | 照原作者的公开分级 | 经验性观感（主观，供选阈值参考） |
|---|---|---|
| < 0.05 | 不烧 / 微微烧 | 基本没有亮面云，不值得抬头 |
| 0.05–0.2 | 小烧 | 地平线附近一小条颜色，天空通透时才好看 |
| 0.2–0.4 | 小烧~中等烧 | **常见的"还不错的晚霞"**，值得顺手拍两张 |
| 0.4–0.6 | 中等烧 | 明显值得看，西侧天空有像样的色带 |
| 0.6–0.8 | 中等烧~大烧 | 值得专程出门，颜色浓、面积大 |
| > 0.8 | 大烧 | 少见，需要云量/通透度/持续时间同时好 |

## 6. 已知局限（读分数前务必知道）

- 全部因子权重与 `1.45` 标定系数都是**复刻假设**，非官方参数，绝对值不可与其他产品比对
- **照明光路的消光只用 AOD 线性近似**，不随太阳高度角与云高变化
  → 低云在日落瞬间的亮度**可能被高估**（例 C 的 0.53 偏乐观）
- 云量两口径常分歧，且该数据通道里 ECMWF 的分层云量与总云量不自洽，**高云有被低估的风险**
- 未在真实 Home Assistant 中加载运行验证，长期稳定性未知；成熟度为**实验性**
- 太阳高度角 >0 时一律不计分（定义上那是"金色时刻"，不是"霞"）
